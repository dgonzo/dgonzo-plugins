# Naming rubric

This file holds the scoring anchors for Pass 2, the generic-name test and the rules for each kind of name. The naming-forge skill reads it before it generates candidates.

## Generic-name test

A name is generic if it fails any of these three checks.

| Check | Fails when |
|---|---|
| Swap test | A competitor or a sibling tool could use the name without changing a letter |
| Category test | The name is the category word itself, such as "Manager", "Hub", "Platform" or "Tool" |
| Image test | The name calls up no concrete thing, action or picture, only abstract nouns |

A generic name can still win. It has to win Pass 1 on clarity, and the output has to say it failed this test.

## Pass 2 scoring anchors

Score each criterion 1, 3 or 5. Use 2 or 4 only when the name sits between two anchors.

| Criterion | 1 | 3 | 5 |
|---|---|---|---|
| Mouth feel | Hard to say aloud or spelled two ways | Easy to say after hearing it once | Easy to say and to spell from hearing it |
| Visual weight | Long or crowded in a command line or heading | Fits but draws no eye | Short and distinct at a glance |
| Cognitive load | Needs an explanation every time | Meaning clear after one use | Meaning guessable from the name alone |
| Longevity | Tied to a version, a trend or a current team | Survives a year of change | Survives a change of scope |
| Namespace clarity | Collides with or reads like a sibling name | Distinct but in a different style from siblings | Distinct and in the same style as siblings |

## Rules for each kind of name

| Kind | Form | Says | Avoid |
|---|---|---|---|
| Product | Two or three syllables | The outcome or the idea | A feature list |
| Feature | A noun that fits in a docs sentence | What the user gets | A style unlike sibling features |
| CLI command | Lowercase, at most 12 characters | A verb for an action, a noun for state | Clashes with common shell commands |
| Repo | Lowercase kebab-case | What the repo holds | A team or person name in a shared repo |
| Plugin | Short lowercase kebab-case | The owner or the domain | Length, since every skill call repeats it |
| Skill | Lowercase kebab-case after `/plugin:` | The job | The method |
| Taxonomy | One grammar for every category | Each case in exactly one category | Overlap or gaps between categories |

## Pass 3 domains

Pick 2 domains that share nothing with the brief. These are starting points. Any domain works if it is far from the brief.

| Domain | Principle to borrow |
|---|---|
| Cooking | Preparation, timing and reduction |
| Sailing | Heading, trim and weather |
| Cartography | Scale, legend and projection |
| Forestry | Growth rings, pruning and canopy |
| Music | Tempo, key and rest |
| Masonry | Load, joint and keystone |
| Medicine | Triage, diagnosis and dose |
| Textiles | Warp, weft and selvage |
