# Marketing tells

Each tell below makes a technical reader stop reading. `signal-cut` checks the draft against every one after pass 3.

The examples are invented to show the shape of a fix. Never copy their numbers or events into a draft.

## The Monday morning test

Picture a working engineer reading the sentence on Monday morning before standup. Keep the sentence only if that reader could act on it that day. Acting means running a command, trying a setting or changing a decision. Cut everything else.

## Tells and fixes

| Tell | Example | Fix |
|---|---|---|
| Adjective in place of a fact | "a powerful, seamless pipeline" | Give the number: "runs 40 jobs in 6 minutes" |
| Promise with no mechanism | "unlock insights across your data" | Say what the tool reads and what it returns |
| Problem with no person | "teams struggle with data quality" | Name the event: "our orders table lost 3 days of rows in March" |
| Feature list | "supports X, Y and Z" | Show one feature solving one problem end to end |
| Superlative | "the fastest way to ship" | Compare against a named baseline with a measured number |
| Invitation to the funnel | "sign up to learn more" | Ask for an action: "clone the repo and run make demo" |
| Hype opener | "we're thrilled to announce" | Open on the problem or the result |
| Rhetorical question | "tired of slow builds?" | State the build time before and after |
| Future-tense vision | "will transform how teams work" | Say what works today and what does not yet |

## Default shapes to break

| Format | Default shape |
|---|---|
| Launch post | Announcement, feature list, quote, sign-up link |
| Blog post | Problem, our solution, benefits, call to action |
| Social thread | Hook question, numbered tips, follow for more |
| Demo script | Slides first, happy path, applause line |
| Newsletter | Company news, links, upcoming events |

| Break that still works | Example |
|---|---|
| Open on the failure | The outage that started the project |
| Terminal before slides | Run the command in the first minute |
| Lead with a limit | What the tool cannot do yet |
| Tell it from the bug report | The ticket text as the opening line |
